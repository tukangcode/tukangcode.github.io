0 Armbian — Apa Itu?

screenshot GitHub page Armbian community

Short story: Armbian itu Linux yang bisa jalan di chip ARM yang dipakai di STB. Namun... tidak semua STB bisa. Community support ada di GitHub page mereka yang melist device apa saja yang compatible.

→ Cek daftar STB support di GitHub Armbian

2 Download Image & Flash ke SD Card

Ok, STB sudah aman (kasus saya: HG680-P pakai chip S905X). Next, soal ISO/image untuk flash-nya — jujur saya pakai Claude untuk bantu carikan room/image dan hasilnya payah... Saya harus cari dan sesuaikan sendiri.

Dalam kasus saya (HG680-P / S905X), saya pakai Bookworm latest release:

screenshot list release Armbian

Jadi kembali lagi — manual job mencocokkan model STB dengan image-nya. Jangan asal pilih, pastikan chip-nya match.

Flash pakai Rufus ke SD Card

▶ Tonton: Cara Flash Image ke SD Card pakai Rufus (YouTube)
1

Download image Armbian yang sesuai chip STB Anda.

2

Download & buka Rufus di PC/laptop.

3

Masukkan SD Card ke card reader USB, colok ke PC.

4

Di Rufus, pilih SD Card sebagai target, pilih file image Armbian.

5

Klik Start, tunggu sampai selesai.

6

JANGAN dulu pasang SD Card ke slot STB. Nanti setelah step terminal.

💡 Storage: SD card lebih stabil daripada flashdisk. Saran: 32GB, minimal 16GB.

3 Boot ke Armbian

Persiapan di STB

Cari aplikasi terminal di STB Anda. Kalau tidak ada, coba Termux (cari cara install-nya kalau tidak ada — biasanya harusnya ada).

Di terminal, ketik:

su

Grant super user ke terminal — izinkan, ya,bolehkan bila pop-up muncul.

Lalu ketik (tapi jangan enter dulu):

reboot update
⚠️ Urutan penting: Masukkan SD Card ke slot STB dulu, baru tekan Enter di terminal. STB akan restart dan boot dari SD Card.
gambar loading booting berjalan

STB akan restart. Jika berhasil, akan masuk ke boot screen seperti di gambar atas. 🎉

First-Time Setup

1

Buat password root — catat! Pilih yang mudah diketik tapi kuat dan aman.

2

Buat nama user — bisa apa saja. Saya pakai root.

3

Masukkan password user — dua kali konfirmasi.

4

Nama device — beri nama STB Anda. Saya kasih root.

5

Locale/bahasa — pilih sesuai angka di list. Untuk default English, pilih Skip generating locale (set ke English). Double-check ya, kurang lebih angka 330 atau skip.

gambar Armbian sukses terinstall

Sudah muncul terminal prompt seperti di atas? Berarti sukses! Tinggal config WiFi/SSH dan install Hermes.

4 Koneksi Internet & SSH

Internet

💡 Saran: Pakai LAN cable — plug and play, nggak perlu ribet setting WiFi manual.

Install & Koneksi SSH

Kalau mau enak kerjanya, install SSH dulu. Dengan SSH, Anda bisa kontrol STB dari PC/laptop/HP tanpa perlu colok keyboard-mouse ke STB terus.

Koneksi SSH dari device lain:

🪟 Windows

ssh user@ip-stb
Via PowerShell atau Terminal

🐧 Linux

ssh user@ip-stb
Via Terminal

📱 Android

ssh user@ip-stb
Via Termux
💡 Tips buat HP: Kalau Anda konek SSH dari HP Android, install Codeboard — keyboard khusus coding yang punya arrow keys, Tab, Ctrl, dan tombol navigasi terminal. Jauh lebih enak daripada keyboard bawaan yang nggak support arrow up/down buat navigasi cmd.
