Meja vs Buku Planning Kenapa Lupa Lanjut

? Versi 30 Detik

Context = meja kerja. Muat terbatas, yang lama dibuang, yang baru datang.

Memory = buku catatan. Permanen, kebaca besok lagi.

Planning = agent bikin rencana sebelum mulai — "langkah 1, 2, 3, baru selesai". Bukan asal jalan.

1 Meja Kerja vs Buku Catatan

Bayangin kamu lagi ujian. Ada dua tempat info:

  • Meja kamu = kertas soal, bolpoin, kalkulator. Space terbatas. Kalau meja penuh, kamu rapikan — buang yang nggak perlu, simpan yang penting.
  • Buku catatan di rumah = semua rumus yang kamu hafal, jadwal kamu, nama temen. Nggak ikut ke meja ujian, tapi kamu tau isinya.

Agent juga punya dua itu:

Di Hermes: context itu obrolan yang lagi jalan sekarang. Memory itu file permanen yang disimpan di ~/.hermes/ dan kebaca tiap sesi baru.

2 Planning — Bikin Rencana Dulu

Agent yang bagus nggak asal jalan. Dia mikir dulu: "langkah apa aja yang aku harus lakuin?" — baru mulai. Bayangin kamu mau masak:

💡 Inti planning: agent pecah tugas besar jadi langkah kecil, kerjain satu per satu, cek tiap langkah. Bukan "ayo bikin semuanya sekaligus".

! Kenapa Agent Bisa "Lupa"?

Context penuh — info lama terbuang

Meja kerja itu kecil. Kalau obrolan sudah panjang, info paling awal bisa "jatuh dari meja". Agent bukan sengaja lupa — info-nya memang nggak muat lagi. Makanya penting: info penting disimpan ke memory, buang cuma di context.

Memory nggak di-activate

Buku catatan ada, tapi kalau agent nggak "buka" bukunya, ya sama aja nggak inget. Di Hermes, memory otomatis kebaca tiap sesi baru — tapi kalau kamu ubah settingan, bisa aja memory nggak ke-load.

Planning hilang di tengah jalan

Agent bikin rencana, mulai eksekusi, tapi di langkah 3 lupa rencana aslinya. Kenapa? Rencananya cuma ada di context, dan context sudah penuh sama hasil tool. Solusi: tulis rencana ke file, buang cuma di kepala.

Di Hermes, kamu bisa liat apa yang agent simpan dengan hermes memory atau cek file di ~/.hermes/. Kalau dia "lupa", cek dulu: apakah infonya ada di memory atau cuma di context?
