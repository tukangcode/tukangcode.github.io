? Apa itu Panduan Induk?

Halaman ini menghimpun:

  • Tutorial STB + Armbian — home server Hermes murah
  • Sumber daya eksternal — docs resmi, repo, tools, komunitas
💡 Tips: Tekan Ctrl + D untuk bookmark. Halaman ini update tanpa ganti URL — cukup refresh.

? FAQ

Apa beda Hermes Agent dengan chatbot biasa?

Chatbot jawab lalu selesai. Agent bisa putuskan panggil tool, baca hasilnya, lanjut reasoning, sampai tugas kelar — loop, bukan sekali jawab. Penjelasan lengkapnya (pakai gambar) ada di Apa itu Agent & Agentic?

Perlu spek tinggi untuk jalanin Hermes?

Tidak. Hermes jalan di laptop biasa, bahkan STB 2GB RAM (lihat STB + Armbian). Yang penting ada Node/Python dan koneksi internet.

Halaman ini bakal update?

Ya. Tiap ada tutorial baru, kartu “Segera” di atas akan jadi tautan aktif. Yang sudah jadi sekarang: Install Hermes Agent, Windows CLI, Windows Desktop, dan Apa itu Agent. Bookmark URL ini — tidak ganti path.
