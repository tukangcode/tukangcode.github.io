2 Pilih Mode: CLI vs Desktop

Hermes bisa dipakai dua cara. Santai, kita bahas satu-satu biar kamu bisa pilih yang paling cocok.

⌨️

CLI

Command Line

Kamu ketik perintah di terminal (layar hitam), lalu Hermes jalanin tugasnya di situ.

  • Ringan, cepat, minim resource
  • Install paling cepat — satu baris curl / irm
  • Cocok buat VPS, STB, server
  • Tidak noob-friendly — harus nyaman dengan terminal
  • Tanpa UI, semua via ketik
Cara install CLI ↓
🖥️

Desktop

GUI App

Bentuknya aplikasi biasa — ada jendela, tombol, dan menu. Tinggal klik-klik, nggak perlu ngoding.

  • User-friendly — noob-friendly, tinggal klik
  • Ada dashboard, chat, settings visual
  • Berat — makan storage ~3 GB + dependensi
  • Install lebih lama (banyak dependensi, build step)
  • Butuh spek sedikit lebih tinggi
Cara install Desktop ↓
🪟 Install di Windows → 🍎 Install di macOS → 🐧 Install di Linux →
Dua-duanya pakai agent yang sama, cuma beda cara pakainya aja. Mau lewat ketikan (CLI) atau lewat klik-klik (Desktop), datanya tetap kesimpan di tempat yang sama — CLI via terminal, Desktop via GUI. Datanya tetap kesimpan di tempat yang sama — di ~/.hermes (Linux/macOS) atau C:\Users\NAMAKAMU\AppData\Local\hermes (Windows). Bagian NAMAKAMU itu nama user Windows kamu, lalu masuk ke folder AppData\Local\hermes.

🪟 Windows

Pilih salah satu: versi CLI yang ringan lewat PowerShell, atau Desktop yang tinggal klik-klik. Dua-duanya punya panduan bergambar sendiri.

🖥️ Syarat Windows: cukup Windows 10 atau 11 — semua edisi jalan (Home/Pro/LTSC). Nggak ada syarat versi tambahan, nggak ada syarat build khusus. Wajib pakai PowerShell untuk install CLI (jangan pakai CMD).

Bingung pilih yang mana? Kalau baru pertama kali, mulai dari CLI — lebih cepat dan lebih kecil. Dua-duanya pakai config yang sama, jadi nggak perlu setup ulang kalau nanti mau pindah.

🍎 macOS

Butuh macOS 12 ke atas. Apple Silicon (M1/M2/M3) didukung penuh. Intel Mac juga bisa, tapi Desktop harus build manual pakai hermes desktop.

CLI — curl satu baris

Terminal
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

Yang kamu butuhin cuma git (coba ketik git --version di Terminal buat cek). Sisanya biar installer yang urus — Python, Node, dan lainnya bakal didownload otomatis kalau belum ada.

source ~/.zshrc # atau source ~/.bashrc

Butuh tanpa interaksi? Tambah --non-interactive. Mau sekalian Desktop dari source? Tambah --include-desktop (butuh build-essential toolchain).

Buka panduan CLI →

Desktop — DMG

  1. Download DMG dari halaman Installation ↗ (atau ZIP).
  2. Buka DMG → drag Hermes.app ke Applications.
  3. Buka Hermes dari Launchpad / Spotlight. Auto-updater ikut di dalam ZIP/DMG.
Sudah ada CLI? Jalankan hermes desktop untuk build Desktop dari source tanpa download DMG.

🐧 Linux

Caranya hampir sama kayak di macOS — cukup satu baris juga. Sudah dicoba di Ubuntu, Debian, dan Arch.

CLI — curl satu baris

Terminal
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

Prasyarat

sudo apt install git curl xz-utils build-essential # Debian/Ubuntu

git wajib, curl + xz-utils untuk download Node (.tar.xz), build-essential / g++ kalau mau build Desktop.

source ~/.bashrc

Desktop di Linux

Belum ada DMG/MSIX seperti macOS/Windows. Build dari source:

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash -s -- --include-desktop

Atau kalau CLI sudah terpasang: hermes desktop

⚙️ Config — CLI (Cara Paling Cepat)

Nggak perlu hadapi wizard panjang dan pesan-pesan config yang bikin bingung. Cukup atur model-nya aja — sisanya bisa nanti.

🎉 Belum punya API key? Pakai yang gratis aja: daftar di Nous Hermes Portal → pilih Tier / Package: Free → kalau diminta kode verifikasi, cek terminal dan masukkan kodenya. Nggak perlu ambil key manual.
1
Atur model & provider
PowerShell / Terminal
hermes setup model

Perintah ini cuma buka bagian model — jadi kamu nggak perlu hadapi wizard setup lengkap beserta pesan-pesan config lainnya. Pilih provider, isi key kalau perlu, pilih model, beres.

  • Mau coba gratis? → daftar di Nous Hermes Portal → pilih Tier / Package: Free → kalau diminta, verifikasi kode dari terminal. Nggak perlu ambil key manual.
  • Sudah punya API key sendiri (OpenAI, Anthropic, Ollama lokal, dll) → pilih providernya di wizard, lalu paste key-nya. Key disimpan di komputermu sendiri — di ~/.hermes/ (Linux/macOS) atau C:\Users\NAMAKAMU\AppData\Local\hermes (Windows).
2
Pilih / ganti model dari dalam Hermes

Nggak perlu keluar dari chat. Jalankan hermes, lalu di dalam sesi chat ketik:

Di dalam chat Hermes
/model # buka daftar model

Tanpa argumen, dia buka pemilih model — tinggal pilih dari daftar. Mau langsung pindah tanpa picker? /model <nama-model> --provider <provider>

3
Cek sehat & tes ngobrol
hermes status # ringkasan komponen
hermes chat # tes ngobrol

Kalau ada yang aneh, hermes doctor buat cek config & dependensi.

4
Gateway (opsional — biar bisa chat dari Telegram/Discord/dll)
hermes gateway

Gateway itu biar Hermes bisa kamu chat dari Telegram, Discord, dan 20+ platform lain. Tiap platform butuh token bot-nya masing-masing — lihat Docs ↗.

💡 Ulang config kapan saja: hermes setup model kalau cuma mau atur model, atau hermes setup kalau memang mau wizard lengkap. File config-nya ada di ~/.hermes/config.yaml (Linux/macOS) atau C:\Users\NAMAKAMU\AppData\Local\hermes\config.yaml (Windows).

🖥️ Config — Desktop (API Key)

Kalau kamu install lewat Desktop (yang ada jendelanya), ngaturnya lewat klik-klik aja, nggak perlu ketik di terminal.

1
Buka Hermes Desktop

Cari Hermes di Start Menu (Windows) atau Applications / Spotlight (macOS), lalu buka aplikasinya.

2
Masuk ke Settings / Configuration

Klik ikon Settings (⚙️) → cari bagian Providers / Models.

3
Atur Provider

Ada dua jalur, pilih salah satu:

  • Provider ada di list resmi (OpenAI, Anthropic, dll) → klik providernya → paste API key di kolom yang disediakan → Save
  • Provider tidak ada / mau pakai custom endpoint → pilih Custom Endpoint → isi Nama Provider, Nama ID, Endpoint, Model List, API Key → Test → Save New Endpoint
  • Mau coba gratis / pakai layanan Nous? → daftar di Nous Hermes Portal → pilih Free → verifikasi kode dari terminal kalau diminta (nggak perlu ambil key manual)
4
Tes chat

Balik ke halaman chat utama, coba kirim pesan. Kalau dibalas sama model, berarti sudah beres!

Desktop dan CLI itu pakai config yang sama. Jadi kamu cukup atur sekali aja — ganti di Desktop, otomatis kebaca di CLI juga, begitu sebaliknya.

! Catatan Penting

⏳ Installer bisa lama — ini normal.
Baik CLI maupun Desktop memang bisa agak lama, soalnya banyak yang didownload. Desktop biasanya lebih lama karena lebih banyak yang harus dipasang. Santai aja, jangan di-cancel di tengah jalan — biarin sampai selesai.
🐢 GitHub di-throttle IndiHome/Telkom?
Kalau download berasa lambat atau stuck pas ambil dari GitHub, coba nyalain VPN atau Cloudflare WARP (1.1.1.1). Di jaringan IndiHome/Telkom kadang GitHub memang agak pelan — pakai WARP/VPN biasanya langsung ngebut lagi.
